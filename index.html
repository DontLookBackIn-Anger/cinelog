为什么推荐 GitHub Gist？ 永久免费、不会休眠、自带私密存储，配合 GitHub Pages / Vercel / Cloudflare Pages 部署最省心。
获取步骤：前往 GitHub → Settings → Developer settings → Personal access tokens (Tokens classic) → 勾选 gist 权限并生成 Token。
Supabase 云端数据库配置： 在 Supabase SQL Editor 中先执行建表语句，再填入 Project URL 与 anon public key。
当前仅使用当前浏览器的本地存储（localStorage）。如需在电脑和手机间自动同步，请切换到上方 GitHub Gist 或 Supabase。
📱 手机 / 另一台设备快捷绑定

在一端配置好后，点击「复制配置口令」发给自己的手机，在手机网页里粘贴即可一键完成绑定，无需手动输入长密钥。
